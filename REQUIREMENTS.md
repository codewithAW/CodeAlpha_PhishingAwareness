# CodeAlpha Task 2 checklist

| Official requirement | Implementation | Verification |
| --- | --- | --- |
| Provide online phishing awareness training | Responsive six-module learning path, local progress, static production build | Browser workflow completes all lessons and reloads the record |
| Teach recognition of phishing emails and fake websites | Email and URL modules plus eight inbox cases and eight simulated site previews | Browser workflow solves every case. Unit suite checks domain extraction and indicator matching |
| Explain attacker social engineering | Authority, urgency, secrecy, familiarity and impersonation lessons plus six branching scenarios | Browser workflow completes all six and checks the recovery branch cannot earn completion |
| Present practical prevention measures | Known-channel verification, MFA and passkeys, payment approval, incident reporting and session revocation | Lesson checks, scenario responses and assessment explanations |
| Include realistic examples and interactive quizzes | Annotated cases, six knowledge checks, 30-question bank, randomized 15-question assessment and answer review | Unit coverage for sampling and scoring. Chromium completes the assessment and checks the review |

Additional delivery includes a responsive dashboard, printable unofficial achievement summary, confirmed reset, modular TypeScript source and repeatable tests.
